# 勇闯娱乐圈：美术资源协作方案

版本：v0.1  
日期：2026-05-28  
用途：明确原型阶段到正式开发阶段的美术资源合作方式，避免过早投入高成本资源，也避免后期资源规格混乱。

## 一、合作原则

当前阶段以玩法验证为先，美术服务于“看懂系统、形成代入、验证气质”。不要一开始追求完整商业品质立绘和场景，而是先用低成本、可替换、规格统一的占位资源跑通体验。

核心原则：

- 先验证玩法，再精修美术。
- 先确定规格，再批量生产。
- 先少量样张试风格，再扩展资产库。
- 所有资源都要能追溯来源和授权状态。
- 角色、场景、UI 的命名和尺寸从第一天就统一。

## 二、阶段划分

### 阶段 1：玩法占位期

目标：支持 Web 原型验证“艺人选取、时间流逝、日程安排、属性变化”。

资源要求：

- 艺人头像或色块头像即可。
- UI 以清晰可读为优先。
- 场景地点先用文字、图标或简单色块表达。
- 不投入正式立绘、CG、复杂背景。

交付物：

- 候选艺人头像占位。
- 行动类型图标占位。
- 地点节点图标占位。
- 简单 UI 色彩与字体方向。

### 阶段 2：风格探索期

目标：确定游戏视觉调性，避免后续资源返工。

需要讨论：

- 整体风格：轻喜剧、黑色幽默、爽文逆袭、娱乐圈解构。
- 角色方向：偏二次元、半写实、国漫、Q 版、杂志感，或混合风格。
- UI 方向：经纪公司后台、娱乐新闻门户、手机热搜界面、通告表格、粉圈社区。
- 色彩方向：轻松明亮，但要带娱乐圈的热闹、浮夸和荒诞感。

交付物：

- 1 页美术风格板。
- 3 到 5 张角色风格样张。
- 1 张主界面 UI mockup。
- 1 张地点探索界面 mockup。

### 阶段 3：资产规格期

目标：把要画什么、尺寸多少、命名如何、优先级怎样定清楚。

建议建立资产清单：

| 类型 | 示例 | 优先级 | 备注 |
|---|---|---|---|
| 艺人立绘 | 初始候选艺人半身像 | 高 | Demo 只需 3 到 5 人 |
| 表情差分 | 普通、开心、压力、愤怒、营业 | 中 | 先给首发艺人做 |
| 地点图 | 公司、培训教室、电视台、影视城 | 中 | 可先用静态背景 |
| UI 组件 | 艺人卡、日程格、属性条、事件弹窗 | 高 | 直接影响可玩性 |
| 图标 | 训练、试镜、休息、公关、营业 | 高 | 先做小尺寸统一图标 |
| 宣传图 | Steam capsule、主视觉 | 低 | 等核心调性稳定后做 |

### 阶段 4：批量生产期

目标：在玩法和风格都稳定后批量产出正式资源。

生产顺序：

1. UI 组件和图标。
2. 首批候选艺人立绘。
3. 首批地点背景。
4. 事件插图或关键 CG。
5. 商店页与宣传物料。

## 三、资源来源策略

### AI 生成

适合：

- 风格探索。
- 概念草图。
- 临时头像。
- 场景氛围草案。

注意：

- 不直接把未筛选的 AI 图当最终商业资源。
- 要统一风格，避免每张图像来自不同世界。
- 重要角色需要后期人工修正或重绘。

### 授权素材

适合：

- 图标。
- UI 装饰素材。
- 临时背景。
- 字体和音效。

注意：

- 记录来源、许可证、是否可商用、是否需要署名。
- 不使用来源不明的网络图片。

### 手绘或外包

适合：

- 主角和核心艺人立绘。
- 关键剧情 CG。
- Steam 商店主视觉。
- 最终统一风格的 UI。

注意：

- 必须先有清晰规格和样张。
- 外包前先确定 Demo 中哪些资源真的会留下。

## 四、当前原型阶段需要的最小美术

当前 Web 原型只需要：

- 4 个候选艺人头像占位。
- 8 个行动类型图标占位。
- 一套经纪公司后台风格 UI。
- 属性条、日程格、事件提示、周结算日志的视觉样式。

暂时不需要：

- 完整立绘。
- 动态 Live2D。
- 复杂场景背景。
- 大量事件 CG。
- Steam 宣传图。

## 五、待确认问题

- 首批角色视觉更偏二次元、国漫、半写实，还是综艺节目包装感？
- UI 是否要模拟“经纪公司内部系统 + 手机热搜界面”的混合风格？
- 艺人立绘是半身像为主，还是头像 + 小人形象为主？
- 是否接受 AI 图作为正式资产的一部分，还是只用于概念探索？
- 资源命名是否统一使用英文 ID，中文名只显示在游戏文本中？
