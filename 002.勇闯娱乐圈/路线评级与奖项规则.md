# 勇闯娱乐圈：路线评级与奖项规则

版本：v0.2  
日期：2026-05-28  
用途：定义不同发展道路下的咖位称呼、资源门槛、奖项目标和成长反馈。底层可以继续使用统一咖位值，但对玩家展示时必须按路线给出更准确的行业身份。

## 一、设计原则

泛用的 L1-L5 只适合做底层数值，不适合直接作为玩家目标。玩家真正需要看到的是：

- 影视演员路线：从小透明、配角、腰部演员到影帝影后。
- 电视剧路线：从网剧新人、平台剧熟脸到视帝视后。
- 音乐路线：从新人歌手、唱作人到歌王歌后。
- 综艺路线：从飞行嘉宾、常驻嘉宾到国民综艺咖。
- 商业路线：从小品牌试水、带货新面孔到品牌宠儿、商业顶流。

因此，系统结构建议分成两层：

- 底层咖位值：由热度、粉丝、口碑、代表作、奖项、商业价值等计算。
- 路线评级称呼：根据艺人的主路线，将咖位值翻译成不同领域的行业身份。

但“主路线”不应由艺人初始固定。艺人可以有初始属性倾向，但路线应由玩家选择的阶段目标和已经兑现的荣誉决定。一个舞台能力强的艺人，也可以被玩家培养成演员、歌手或商业明星。

## 二、路线形成规则

路线形成建议采用“能力培养 + 阶段目标 + 荣誉沉淀”的结构：

1. 玩家签约艺人，艺人只有初始优势、短板和个性标签。
2. 系统抛出若干阶段目标，例如歌唱比赛、影视项目、综艺试录、品牌推广。
3. 玩家选择目标，并在期限内通过地图项目提升对应能力。
4. 到期验证门槛是否过关。
5. 成功后获得对应领域荣誉，荣誉反过来影响路线称号、咖位值和资源解锁。

路线称号不是“职业树升级”，而是玩家履历的总结。谁的荣誉最高，当前路线展示就倾向谁；多领域都有荣誉时，可以形成双栖、转型、跨界等复合称号。

## 三、现实规则参考

影视与剧集奖项可参考现实中的评奖结构：

- 内地电影三大奖：金鸡奖、百花奖、华表奖。
- 剧集三大奖：飞天奖、白玉兰奖、金鹰奖。
- 音乐领域可参考金曲奖的歌王、歌后、年度歌曲、年度专辑、最佳新人、最佳作词、最佳作曲等奖项结构。

游戏内可以直接参考这些规则的结构：新人奖、配角奖、主角奖、作品奖、观众奖、官方奖、专业奖、商业榜单奖。但正式游戏中是否使用真实奖项名称，需要后续单独确认授权、合规和题材风险。原型阶段可以先使用架空等价名。

## 四、影视演艺路线

适用于以电影、电视剧、剧集表演为主的艺人。该路线核心看演技、代表作、口碑、资源等级和奖项。

| 底层等级 | 展示称呼 | 典型资源 | 代表成果 | 奖项目标 |
|---|---|---|---|---|
| L1 | 表演新人 | 表演课、小短片、群演、低成本网剧试镜 | 有镜头、有台词、能完成基础表演 | 新人提名、短片单元入围 |
| L2 | 小透明演员 | 网剧配角、短剧主角、普通剧组试镜 | 开始被观众认脸 | 平台新人奖、最佳新人提名 |
| L3 | 腰部演员 | 平台剧重要配角、单元剧主角、类型片配角 | 有稳定作品和讨论度 | 最佳男/女配角提名、年度潜力演员 |
| L4 | 一线演员 | 重点剧主角、院线电影重要角色、头部 IP | 能扛项目、能带招商 | 最佳主角提名、热门剧集演员奖 |
| L5 | 影帝 / 影后 / 视帝 / 视后 | S 级电影主角、头部剧集主角、奖项冲刺项目 | 代表作破圈，行业认可 | 最佳男/女主角、三大奖或剧集大奖 |

### 分支说明

- 电影演员偏“影帝/影后”：更看电影作品质量、院线成绩、专业奖项。
- 剧集演员偏“视帝/视后”：更看剧集热度、播出平台、角色国民度和剧集奖项。
- 商业演员偏“一线扛剧/扛票房”：不一定拿奖，但能带流量和招商。

## 五、音乐路线

适用于歌手、唱作人、偶像歌手、音乐制作型艺人。该路线核心看唱功、创作、作品传播、专辑质量、舞台表现和奖项。

| 底层等级 | 展示称呼 | 典型资源 | 代表成果 | 奖项目标 |
|---|---|---|---|---|
| L1 | 音乐新人 | 声乐训练、翻唱、小样录制、地下演出 | 形成声音记忆点 | 新人推荐、校园/平台新声 |
| L2 | 新人歌手 | 单曲发行、音乐节小舞台、网综舞台 | 有第一首出圈歌或粉丝盘 | 最佳新人提名、平台新歌榜 |
| L3 | 上升歌手 / 唱作人 | EP、OST、固定音乐综艺、制作人合作 | 有稳定作品输出 | 年度新人、最佳作词/作曲提名 |
| L4 | 一线歌手 | 正式专辑、巡演、头部音乐节目、品牌主题曲 | 有代表作和演唱会能力 | 年度歌曲、年度专辑、最佳歌手提名 |
| L5 | 歌王 / 歌后 / 金牌唱作人 | 大型巡演、奖项冲刺专辑、跨年压轴 | 作品和现场双认可 | 最佳男/女歌手、年度专辑、年度歌曲 |

### 分支说明

- 唱作人路线：更看创作和专辑口碑。
- 流行歌手路线：更看唱功、传唱度和舞台。
- 偶像歌手路线：更看粉丝盘、舞台和商业价值，但专业奖项门槛更高。

## 六、综艺路线

适用于综艺咖、主持型艺人、反应型艺人、热梗艺人。该路线核心看综艺感、情商、临场反应、路人缘和人设稳定度。

| 底层等级 | 展示称呼 | 典型资源 | 代表成果 | 奖项目标 |
|---|---|---|---|---|
| L1 | 通告新人 | 小型访谈、平台短综、直播连线 | 能接梗，不怯场 | 平台综艺新人 |
| L2 | 飞行嘉宾 | 综艺飞行、棚综试录、品牌直播 | 有可剪辑名场面 | 年度综艺新面孔 |
| L3 | 常驻嘉宾 | 腰部综艺常驻、观察室嘉宾 | 人设稳定，有固定观众 | 年度综艺表现奖 |
| L4 | 头部综艺咖 | 黄金档常驻、平台招商综艺 | 有国民梗和商业价值 | 最受欢迎综艺艺人 |
| L5 | 国民综艺咖 / 主持核心 | 头部节目核心位、跨年主持、晚会主咖 | 观众缘稳定，能带节目 | 年度主持/综艺人物 |

### 分支说明

- 热梗路线涨得快，但口碑风险高。
- 主持路线更看稳定和情商。
- 观察室/谈话类路线更看表达和观点输出。

## 七、商业路线

适用于时尚、代言、直播带货、品牌合作路线。该路线核心看粉丝购买力、路人缘、形象稳定度、品牌契合度和风险控制。

| 底层等级 | 展示称呼 | 典型资源 | 代表成果 | 奖项目标 |
|---|---|---|---|---|
| L1 | 商务试水 | 小品牌物料、探店、直播试播 | 能完成基础商业转化 | 平台商业新人 |
| L2 | 带货新面孔 | 腰部直播、区域品牌、杂志内页 | 有基础转化数据 | 新锐商业艺人 |
| L3 | 品牌合作艺人 | 中型代言、杂志封面、品牌活动 | 有稳定品牌合作 | 年度商业潜力 |
| L4 | 品牌宠儿 | 头部品牌推广、大刊封面、红毯资源 | 商业价值明显 | 年度商业价值艺人 |
| L5 | 商业顶流 | 高奢合作、国民品牌代言、头部直播档 | 能带动销售和话题 | 年度品牌影响力 |

### 分支说明

- 商业路线可以不等于专业路线成功。
- 高商业价值会反哺资源，但过度商务会损伤口碑。
- 塌房、恋情、粉丝冲突会直接影响品牌安全度。

## 八、奖项与头衔的设计方式

建议奖项分成四类：

| 奖项类型 | 现实参考 | 游戏作用 |
|---|---|---|
| 专业奖 | 金鸡、飞天、白玉兰、金曲等 | 提升口碑、解锁高阶资源 |
| 观众奖 | 百花、金鹰等偏观众参与奖项 | 提升粉丝、热度和路人缘 |
| 官方/行业奖 | 华表、行业协会类奖项 | 提升行业背书和公司声誉 |
| 商业榜单 | 音乐榜、品牌榜、热搜榜、带货榜 | 提升短期热度和商业价值 |

### 头衔规则

同一个 L5，按路线展示不同头衔：

- 电影表演：影帝 / 影后。
- 剧集表演：视帝 / 视后。
- 音乐演唱：歌王 / 歌后。
- 音乐创作：金牌唱作人 / 金牌制作人。
- 综艺路线：国民综艺咖 / 头部主持人。
- 商业路线：商业顶流 / 品牌宠儿。

## 九、原型落地建议

Web Demo 下一步应改成：

- 保留统一咖位值作为底层。
- 每位艺人不再拥有固定主路线，而是拥有初始属性倾向。
- 界面展示“当前路线评级”，例如“L2 小透明演员”“L3 上升歌手”，该评级由荣誉和阶段目标结果决定。
- 地图项目根据路线显示不同门槛和资源名称。
- 奖项系统先用架空名称，但结构参考现实奖项。

示例：

- 林小棠：舞台 / 综艺路线，L2 显示“飞行嘉宾”，L5 显示“国民综艺咖”。
- 江澈：影视路线，L2 显示“小透明演员”，L5 显示“影帝/视帝候选”。
- 温然：音乐路线，L2 显示“新人歌手”，L5 显示“歌王/歌后”。
- 乔一一：综艺 / 商业路线，L2 显示“热梗新人”，L5 显示“商业顶流”。
