# 勇闯娱乐圈：规则与问题记录

本文档用于记录项目推进过程中反复需要遵守的关键规则、设计约束、已发现问题和待澄清事项，方便后续实时查询，避免重复犯错。

## 使用约定

- 用户提到关键规则、禁忌、偏好或必须遵守的设定时，及时整理到本文档。
- 已经确认的规则放入“关键规则”。
- 发现的设计风险、实现问题、表述误区放入“问题记录”。
- 尚未拍板但会影响后续设计的问题放入“待澄清事项”。
- 修改文档时尽量保留时间和简短背景，方便回溯。

## 关键规则

- 2026-05-28：先围绕“基础体验”讨论游戏的核心定位、主循环、差异化和核心系统，达成共识后再进入具体游戏开发环节。
- 2026-05-28：关键规则、禁忌、偏好、已踩坑问题需要及时整理成本地 Markdown，方便实时查询，避免重复犯错。
- 2026-05-28：主角经纪人的身份、性格和过往不可自定义；可以设计固定主角与固定叙事口吻。
- 2026-05-28：初始艺人从候选池选择，但开局只能签约 1 位；后续随经营扩大逐渐开放更多候选和签约名额。
- 2026-05-28：游戏调性偏轻喜剧、黑色幽默、爽文逆袭、娱乐圈解构、看乐子和实时热梗融合，不做现实残酷向。
- 2026-05-28：允许玩家做灰色或不道德经营选择，但必须有游戏内惩罚、反噬或长期代价。
- 2026-05-28：允许艺人恋爱和官宣，但恋爱与亲密关系内容不做色情向表达。
- 2026-05-28：舆论系统偏戏剧化、夸张和可控，不追求现实残酷感。
- 2026-05-28：艺人在特定情况下会违抗玩家安排，信任度是关键触发条件之一。
- 2026-05-28：公司阶段先不引入外部竞争对手，优先聚焦内部经营和艺人与艺人之间的竞争。
- 2026-05-28：首个 Demo 先做本地原型，长期目标是 Steam PC。
- 2026-05-28：核心系统方向暂时认可，可以先从“日程系统”和“艺人系统”进入开发验证。
- 2026-05-28：Web Demo 不应是简单日历排班推进；需要体现地图系统。玩家平时可以在地图上移动，在不同地点选择项目消耗精力强化艺人；精力条耗尽后不能继续行动，只能推进时间恢复精力。
- 2026-05-28：Web Demo 必须明确显示精力数值，不能只靠进度条表达。
- 2026-05-28：娱乐圈成长体系必须体现“咖位等级 / 资源大小 / 金字塔梯度”的对应关系。这是重中之重；没有资源等级成长，地图和属性成长都不成立。
- 2026-05-28：需要引入每周随机事件，有好有坏，真实作用于艺人，并要求玩家处理解决，增强不确定性。
- 2026-05-28：L1-L5 只能作为底层数值，不应作为唯一玩家可见评价。不同发展道路需要定制评级称呼和奖项目标，例如影视路线的小透明演员、腰部演员、影帝/影后；音乐路线的新歌手、上升歌手、歌王/歌后。
- 2026-05-28：路线评级与奖项结构可以参考现实娱乐圈规则：电影三大奖、剧集三大奖、音乐奖项、商业榜单等，但正式使用真实名称前需要确认授权和合规风险。
- 2026-05-28：艺人发展路线不应由初始角色固定。玩家应通过培养不同能力、选择不同目标活动并兑现成果，逐渐积累对应领域的荣誉和咖位称号。
- 2026-05-28：需要阶段性验证空间。每隔一段时间给玩家若干可选小目标，例如歌唱比赛、影视项目、综艺试录、商业合作；玩家选择目标后围绕要求养成，到期后根据能力是否过关结算荣誉、资源和反作用。
- 2026-05-28：游戏基础流程明确为：选择初始艺人 -> 选择发展目标 -> 每周活动推进 -> 属性成长和反馈。
- 2026-05-28：目标选择必须以弹窗形式出现，玩家进行目标 N 选 1；完成有奖励，未完成有粉丝、舆论等惩罚，不能只是页面里的普通卡片。
- 2026-05-28：初始艺人选择需要是单独界面。玩家能看到艺人人设和标签，展开后查看详细属性，再决定签约。
- 2026-05-28：阶段目标选择需要支持“无发展目标 / 躺平”选项，允许玩家不追求明确目标，但要承担成长放缓或机会流失。
- 2026-05-28：番位提升后必须弹出窗口提示，让玩家感受到等级、荣誉和资源跃迁。
- 2026-05-28：地图项目不应因番位不足直接不可选。低番位也可以尝试高阶项目，但大概率会被拒绝，并用戏剧化反馈体现娱乐圈“看人下菜碟”的势利心态。
- 2026-05-28：需要新增手机系统，作为热搜资讯、娱乐爆料、其他艺人和制作人消息的入口。手机信息应帮助玩家判断本周机会、风险和行业风向。
- 2026-05-28：艺人培养不能只是数值提升，必须体现两面性和“活人感”。例如培养感性意识会提升作品理解力，但也可能提高恋爱、私生活、狗仔曝光和热搜风险。
- 2026-05-29：人格倾向与状态监控需要拆开。恋爱风险、压力、信任应归为同一类动态监督项，而不是混在人格倾向里；人格倾向主要表达角色底色、行为偏好、成长副作用和违抗方式。
- 2026-05-29：专业属性应保持为 5 个必要基础能力，但玩家可见命名保持大众化和娱乐圈语感，不直接使用“声台形表”式学院派命名。通用化只作为内部设计原则。暂定为“唱功、演技、舞台、魅力、创作”，其中魅力合并原“综艺”和“魅力”，创作适用于演艺、歌唱、唱跳、综艺内容和短视频营业等多个领域，体能不再作为独立专业属性。
- 2026-05-29：专业属性展示采用“五芒星图 / 柱状图”切换。五芒星图看能力轮廓和偏科程度，柱状图看具体数值、变化来源和项目门槛；市场、状态、人格不混入同一张专业属性图。
- 2026-05-29：时间系统需要更具象化，不能只显示“第几周”。界面左上方应有日历按钮，点击弹出日历界面；日历中需要看到当前时间、活动目标、目标截止周和世界发生的大事，用来强化时间压迫感。
- 2026-05-29：文档修改记录需要同步到飞书云文档，不能只改本地 Markdown。
- 2026-05-29：除非用户明确要求“打包”，否则不要主动生成新的 zip 包；完成 Demo 修改后只需说明本地试玩地址和验证结果。
- 2026-05-29：娱乐圈金字塔不应长期占据主界面空间，应收缩为按钮入口；玩家点击后弹窗查看完整咖位等级排行、当前等级、下一档门槛和奖项目标。
- 2026-05-28：不同年龄艺人应有不同感情、婚姻、粉圈和八卦倾向。养成系/年轻爱豆恋爱风险更高，成熟艺人可延展到婚姻、家庭、转型和公众期待。
- 2026-05-28：初始艺人池需要覆盖不同知名度、资本背景和粉丝量。京圈公主、当红养成系男团成员等模板应体现资源多少、发展难度和舆论风险的明显差异。
- 2026-05-28：经纪人手机不应作为常驻信息块塞在主流程里，应以界面图标存在；玩家点击手机图标打开手机界面，查看热搜和联系人消息，点击空白处或关闭按钮退出。
- 2026-05-28：手机图标需要有足够强的可见性；当热搜、联系人或周更资讯出现未读内容时，必须显示红色感叹号提示，玩家打开手机后清除未读状态。
- 2026-05-28：资本支持度必须真正影响资源获取。高资本艺人应更容易进入高阶目标和资源局，例如 S 级主演、头部商务；但仍可能承担资源咖争议、口碑反噬和全网审判。
- 2026-05-28：行动反馈需要加入对话系统。玩家执行项目后，应得到制作人、演员导师、综艺导演、公关负责人等对应负责人的反馈，语气偏黑色幽默和娱乐圈讽刺。
- 2026-05-28：地点项目执行后的反馈不应只出现在页面顶部事件文本里，必须以弹出对话框形式做强提示；对话框需显示项目名、地点、负责人反馈和剩余精力。
- 2026-05-29：玩家身份是经纪人，也是资本入口。玩家对艺人拥有捧红、压资源、雪藏等强权影响，艺人对玩家存在依附关系和情感表达；事业选择、资源试探、舆论事件处理后，应通过手机私信传达艺人的顺从、信任、戒备或不安。
- 2026-05-29：手机不只是资讯入口，也要承担艺人与经纪人的情感对话。艺人私信内容需要根据信任度变化调整语气：高信任偏托付和共谋，中信任偏试探和配合，低信任偏恐惧、戒备和被控制感。
- 2026-05-29：日历、手机、排行等工具入口统一收束到界面右下方，不分散在顶栏或主流程内容里；主界面只保留信息摘要，完整信息通过工具按钮弹窗查看。
- 2026-05-29：地点移动反馈不应放在页面上方常驻提示条里，应以屏幕中央飘字出现并渐隐消失，避免打断主界面信息结构。
- 2026-05-29：当前阶段目标必须比普通信息卡更突出，使用更强对比色和截止时间标签强化目标感。
- 2026-05-29：主流程界面不再放置娱乐圈金字塔摘要模块；排行只通过右下角工具入口打开弹窗查看。
- 2026-05-29：本周精力放在地图左上角，作为地图行动的直接资源提示；顶栏不再重复放置精力信息。
- 2026-05-29：地图地点 hover 不能破坏地点定位。地图节点使用居中定位时，hover 状态必须保留原始 `translate(-50%, -50%)`，不能被全局按钮 hover 覆盖导致标签大幅偏移。
- 2026-05-29：专业属性下方不放不清晰的路线荣誉小格说明；如果后续需要展示荣誉，应另设明确的荣誉/履历模块，而不是混在专业属性下方。
- 2026-05-29：随机事件必须以弹窗形式出现，玩家处理前阻塞地图项目和周推进；不要作为普通卡片混在地图主界面里。
- 2026-05-29：顶栏只保留原型版本号和重置按钮。周期、当前艺人、评级等信息不放在顶栏，避免顶部信息噪音过重。
- 2026-05-29：随机事件处理后必须有明确反馈，至少用弹窗或跳字说明玩家选择造成的结果和数值变化，不能只让玩家看到精力减少。
- 2026-05-29：咖位升级不能只依赖咖位值。必须采用“基础咖位值 + 路径关键事项”双条件：数值够了只是具备资格，还需要作品出现、舞台出圈、热度综艺、商务成果等路径事件，才能真正升咖。
- 2026-05-29：资金资源重新作为经纪公司经营循环进入 Demo。公司有初始资金，签约艺人和培训/资源项目会消耗资金；艺人签约后每周产生回款，回款取决于热度、粉丝、口碑、咖位以及当周是否做营业活动；资金归零则公司破产，游戏结束。
- 2026-05-29：人格倾向必须显性化“改变来源”和“后果”。项目卡需要展示哪些行动会提高感性、野心、恋爱倾向、自律；角色栏需要说明高/低人格会触发什么风险，例如恋情曝光、主动抢资源、自律崩盘、违抗安排等。
- 2026-05-29：角色展示需要加入市场定位与评级思路。不同角色应有天然定位，例如舞台萌新、低热度口碑演员、资本资源咖、高粉爱豆；定位要提示最快成长路径，并影响玩家对地图地点和项目的选择。
- 2026-05-29：咖位提升后，地图地点应解锁更高性价比项目。高咖位不只是能“硬闯”高资源，也应让影视城、电视台、唱片公司、粉丝社区等地点出现更划算的邀约、通告或商务回款选项。
- 2026-05-29：公司资金入口放在页面右上角，点击弹出资金详情界面。资金详情需展示当前库存资金、即将回款资金、艺人基础收入、营业加成、运营成本和预计净变化。
- 2026-05-29：艺人压力过大且信任过低时，可能触发“艺人提出解约”或“艺人对簿公堂”事件。处理方式应造成资金赔偿、口碑损失、信任变化，严重时可提前结束本轮。
- 2026-05-29：Demo 暂定完成 5 轮阶段目标选择/结算后解锁结局。结局需要给出玩家经纪人事业小结、艺人生涯小结、公司资金、最终咖位、主路线和最高荣誉，本轮游戏结束。
- 2026-05-29：咖位弹窗必须先呈现不同领域标签，例如影视演艺、音乐唱作、综艺舞台、商业热度。玩家点击领域标签后，进入对应领域的序列等级金字塔；不能只根据系统推断主路线自动展示，否则玩家会困惑当前看到的是哪条咖位线。
- 2026-05-29：右侧艺人状态栏不显示咖位摘要和公司资金摘要。咖位信息统一从右下角“咖位”按钮进入，资金信息统一从右上角“公司资金”按钮进入，避免同一信息在多个位置重复展示。
- 2026-06-01：地图地点不应开局全部解锁。初始开放公司办公室、培训教室和粉丝社区；影视城、唱片公司、电视台等资源地点需要公司花费资金解锁。玩家点击未解锁地点时，应弹出解锁费用确认窗口，确认后扣除资金、开放地点并进入使用；资金不足时不能确认解锁。
- 2026-06-01：会议确认当前 Demo 最大问题是养成过程仍偏“刷日常堆数据”，后续必须强化机会成本和强分岔选择，让玩家意识到自己在左右艺人职业发展，而不是把每周精力平均点满。
- 2026-06-01：后续方向可尝试“放置模拟经营 + 关键事件选择”。艺人平时可自动成长或营业，玩家重点处理团体/solo、赚钱/成长、压榨/保护等互斥决策；同期艺人数量不宜过多，避免玩家记不住角色。
- 2026-06-01：艺人数值应拆为专业属性和互动/关系/拟真属性两层。专业属性表示唱功、演技、舞台、创作等能力；关系层表示艺人对玩家的信任、亲近、压力、好感和可攻略关系，并影响违抗、解约、亲密互动和项目推进。
- 2026-06-01：MBTI 可作为角色标签 AB 测试方向，但不能直接定案。需要比较“当前文字化人格属性”和“MBTI + 简短标签说明”两种角色卡，看玩家哪种更容易理解。
- 2026-06-01：可以新增美容院/造型室等外形管理地点，但必须克制表达。事件应围绕上镜显胖、粉丝吐槽、拍照角度、滤镜偏好等具体处境，服务艺人活人感和经纪人选择，避免单纯贩卖容貌焦虑。
- 2026-06-01：解约机制后续可从失败结局扩展为市场流通。模拟经营方向下，解约艺人可能退休、流入竞争对手或重新进入市场；公司规模提升后可解锁法务、精算、合同等更黑色幽默的资本工具。
- 2026-06-01：体验反馈确认“每天/每周都要选择养成项目”过于繁琐且不够爽。后续改动应在两条方向中取舍：一是保留高频选择但把选择做得更爽、更戏剧化；二是减少日常选择，转向多艺人签约、路线设定、自动成长、玩家只参与重大决策的模拟经营体验。
- 2026-06-01：模拟经营改造第一版规则：玩家可通过右下角“艺人”按钮打开艺人管理界面，签约多名艺人；每名艺人可规划未来一个月发展路线，确认前显示预算、成长方向和回款，确认后扣除资金；推进时间时艺人自由行动并自动获得属性、市场变化和资金回款；过程中以弹窗形式触发重大决策。艺人解约、地点学习、地点资金解锁等既有设定保留。
- 2026-06-02：体验反馈确认“多艺人月度路线逐个确认”仍然增加了无意义操作，只是把繁琐从每日养成转移到多人行程安排。后续应继续减少低价值确认，改为默认策略、批量规划、异常提醒和重大决策介入，而不是让玩家反复确认每个艺人的普通行程。
- 2026-06-03：模拟经营视角抬高后，需要防止玩家和艺人之间情感变淡。后续设计应采用“公司经营高视角 + 艺人关键情感触点”的结构：日常少打扰，重大选择、压力临界、信任变化、成功/失败节点必须通过手机私信、谈心、亲密/疏离反馈和专属事件强化艺人活人感。
- 2026-06-03：主循环调整为公司经营者视角：签约艺人 -> 设定长期定位 -> 选择公司本月策略 -> 自动推进 -> 只处理重大事件/异常 -> 月末总结。
- 2026-06-03：日常自动化，情感不自动化。艺人日常成长、营业、回款由系统按长期定位和公司策略推进；但重大选择、异常、压力临界、信任变化、成功/失败节点必须通过弹窗、手机消息或专属事件反馈给玩家。

## 问题记录

- 2026-05-28：已修复 Web Demo bug。完成第一轮目标后，如果同一周出现随机事件，第二轮目标选择按钮会被 pendingEvent 禁用，导致无法选择目标。修复原则：目标选择流程优先，随机事件保留但不阻塞目标选择。
- 2026-05-29：五芒星图在艺人状态栏中不明显。原因：专业属性模块位置排在人格倾向之后，右侧栏高度有限时容易被折到下方；且展示模式会被本地状态记住，若切过柱状图，刷新后不会默认看到五芒星。修复原则：专业属性模块提前到艺人基础信息之后，放大五芒星图，并通过新存储版本重置默认展示为五芒星。
- 2026-05-29：用户截图仍显示旧版 UI（主界面完整金字塔、专业属性含“综艺/体能”）。原因：本地 5177 服务源码已更新，但历史 dist 包仍停留在旧版本；若打开旧包或浏览器缓存旧 app.js，会看到旧界面。修复原则：Demo 页面必须显示可见版本号，index.html 的 CSS/JS 引用添加版本参数；未被明确要求打包时，dist 旧包不代表最新 Demo。
- 2026-06-03：v2.6 验证时发现策略周期最后一周可能同时出现随机事件和月末总结，导致玩家不知道先处理哪个弹窗。修复原则：策略周期结算时优先月末总结，本周不再抽随机事件；月末总结关闭后再进入下月策略选择。
