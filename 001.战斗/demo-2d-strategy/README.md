# M98 2D Strategy Combat Demo

这是一个轻量 2D 浏览器原型，用于验证 M98 当前战斗策略方向：

- 回合策略底层，但画面保持对峙和行动条推进。
- 玩家每轮选择武器、技能和 Boss 部位。
- 武器与部位存在适配关系：大剑破盾、拳套破斧臂、弓弩打核心。
- 部位有生命和韧性，击破后影响 Boss 行动与威胁。
- Boss 会触发高威胁快反窗口，需要格挡、左闪或右闪。
- 灵魂铠甲能量由攻击、破部位和反制获得，满后释放奥义。

## 运行方式

直接双击 `index.html` 即可运行。

也可以在本目录启动本地服务：

```powershell
python -m http.server 5177
```

然后打开 `http://localhost:5177`。

## 当前验证重点

1. 一轮行动里玩家是否能清晰理解“武器 - 部位 - 结果”。
2. 部位破坏是否真的改变战斗节奏，而不是只显示伤害数字。
3. 快反窗口出现频率是否增强压迫感，而不是打断思考。
4. 灵魂铠甲奥义是否像阶段性爆发，而不是普通技能。
5. 大剑、拳套、弓弩是否有可感知的策略差异。
