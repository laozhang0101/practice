# M98 策略简化版 Demo

这是从策略版独立拆出的轻量验证工程，目标是保留完整的战前与战中流程，同时减少战斗中的信息负担。

## 保留

- 选择 Boss
- 战前选择一把武器
- 战前最多选择两个挂件，进入战斗后锁定
- 武器决定固定技能组与战斗节奏
- 原策略版的三套主动技能配置与伤害数值
- 拳套技能视频、4FPS 技能帧动画及表现后伤害结算
- 拳套连击、大剑防御姿态与弹反、弓弩弹药消耗
- 无人机协同、喷气近战增幅、方舟供能、肩炮追加攻击与酒葫芦恢复
- 严格的玩家/怪物轮流行动
- 行动力消耗与恢复
- 怪物出手时的格挡、左闪、右闪

## 移除

- 怪物部位及部位血条
- 技能攻击部位与目标选择
- 战斗中武器切换
- 部位破甲、部位摧毁与对应增伤
- 灵魂战甲等额外系统

直接通过静态服务器打开 `index.html` 即可体验。

技能视频与帧动画从原策略版按原文件复制到本工程，不转码、不改帧、不覆盖原工程资源。
