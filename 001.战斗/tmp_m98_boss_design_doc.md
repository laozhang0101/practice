# M98 Boss设计原则与原型方案

## **1. 设计目标**

M98 的 Boss 设计不应该只是“更厚血的精英怪”，而应该承担 4 个核心职责：

- 验证主战斗结构
- 验证构筑差异
- 验证策略解题
- 产出战斗高光

更具体地说，Boss 要让玩家在一场战斗里同时感受到：

- 我看得懂它在干什么
- 我知道我为什么输了
- 我知道我该换什么思路
- 我这套战士构筑真的打出了自己的风格
- 我在关键节点打出了漂亮的反制或爆发

所以 M98 的 Boss 设计重点，不是“做难”，而是“做出可读、可解、可高光的压力”。

## **2. Boss设计原则**

### **2.1 题面必须清晰**

Boss 最重要的是题面，不是数值。

题面清晰的意思是：

- 玩家能从外观、部位、姿态、前摇、特效里读出信息
- 玩家能知道“这个阶段该怎么打”
- 玩家能知道“哪个部位、哪种武器、哪种策略更有效”
- 玩家失败后能复盘原因，而不是只觉得被数值碾了

对 M98 尤其重要，因为战斗一直在强调：

- 外观即战斗方式
- 解题感
- 策略和视觉的联系

所以 Boss 必须自带“线索系统”。

### **2.2 压力优先来自机制，而不是纯数值**

Boss 的压力来源应该优先是：

- 部位机制
- 阶段变化
- 姿态变化
- 威胁动作
- 资源压迫
- 反应窗口

而不是单纯：

- 攻高血厚
- 一套秒人
- 容错极低

因为 M98 不是纯反应型动作 Boss，而是“能观察、能判断、能调整”的 Boss。

### **2.3 Boss必须服务构筑验证**

Boss 不是独立存在的，它要帮助玩家验证自己的 build。

所以一个合格的 Boss 应该能回答这些问题：

- 我这把武器为什么在这里好用
- 我这套灵魂铠甲为什么适合这个 Boss
- 我带的挂件到底有没有价值
- 我是靠什么赢的：破甲、反击、拉扯、压制、爆发，还是持久消耗

如果 Boss 无法体现构筑差异，那武器、灵魂铠甲、挂件那整套设计就会悬空。

### **2.4 Boss必须有“过程中的最优解”**

会议里一个很重要的判断是：

> 最优解不是一个结果，而是一个过程。

这应该直接成为 Boss 设计原则。

也就是说：

- Boss 不能只有一个固定解
- 玩家要在不同阶段不断调整
- 同一个 Boss 不同构筑可以打出不同解法
- 但不同解法都应该是“可解释”的，不是瞎打

### **2.5 高光必须来自战斗过程**

Boss 战里的高光要尽量来自：

- 破韧窗口
- 部位破坏
- 成功格挡/闪避后的反打
- 灵魂铠甲奥义释放
- 武器切换后的精准追击
- 阶段转换前后的压制

而不是只靠终结演出。因为 M98 要的是“构筑兑现感”，不是单纯收尾爽感。

## **3. Boss设计的核心内容**

### **3.1 身份层**

回答“这是什么 Boss”。

包括：

- 体型和轮廓
- 战斗风格
- 核心威胁方式
- 主要弱点形式
- 对应的战士幻想

示例类型：

- 重甲壁垒型
- 高机动猎杀型
- 多部位异化型
- 灵能施法压制型

### **3.2 部位层**

M98 的 Boss 很适合做部位化，因为这能直接服务：

- 武器差异
- 解题感
- 视觉反馈
- 破坏快感

部位层建议至少承载这些功能中的一部分：

- 部位护甲值不同
- 部位被破坏后技能失效
- 部位被破坏后进入弱点窗口
- 不同武器对不同部位效率不同
- 部位变化影响姿态和阶段

关键原则是：部位不能只是“多几个命中点”，而必须带来决策变化。

### **3.3 姿态层**

姿态很适合 Boss，因为它天然能做题面变化。

一个 Boss 可以有 2 到 3 个姿态，例如：

- 防御姿态：高护甲、慢、强压迫
- 攻击姿态：高威胁、高破绽
- 敏捷姿态：多位移、多连续技、脆但难命中

姿态系统的价值在于：

- 不需要做太多新 Boss，也能让单 Boss 有变化
- 能直接驱动玩家换武器、换思路
- 能把战斗节奏打得更鲜明

### **3.4 阶段层**

Boss 的阶段变化不应该只是“血量掉了换招”。

更好的阶段变化应该和这些挂钩：

- 部位破坏
- 破甲
- 灵能暴走
- 关键部件激活/损坏
- 外观变化
- 战场状态变化

这样阶段变化才会和“外观即战斗方式”“策略有视觉联系”形成统一。

### **3.5 威胁层**

Boss 的威胁动作建议至少分成三类：

- 常规压迫动作
  - 用来维持节奏和持续压力
- 高威胁动作
  - 用来触发闪避 / 格挡 / 反击窗口
- 机制动作
  - 用来迫使玩家改变策略，而不是只拼操作

### **3.6 奖励层**

Boss 要让玩家在正确决策后得到明确奖励。

奖励形式可以包括：

- 破韧
- 部位破坏
- 硬直
- 技能封锁
- 伤害倍率窗口
- 灵魂铠甲奥义收益提升
- 追击机会
- 行动力恢复

这决定“解题”到底值不值得。

## **4. 适合M98系统的Boss原则细化**

### **4.1 优先验证“武器 x 部位 x 灵魂铠甲”**

对 M98 来说，Boss 最该验证的不是单纯技能搭配，而是：

- 武器负责“怎么破”
- 部位负责“破哪里”
- 灵魂铠甲负责“在什么时机打出高光或完成对抗”

挂件则是修正器，而不是主解。

### **4.2 Boss必须有可观察的解题线索**

线索来源建议固定化：

- 外观轮廓
- 特定部位材质
- 发光区域
- 姿态切换
- 特殊前摇
- 被击中反馈
- 阶段转换表现

最好做到：第一次未必能完全理解，但第二次就能明显更懂。

### **4.3 Boss不能只靠固定轮次表**

因为 M98 想强调“过程中的解题”，所以 Boss 最好有：

- 有限随机
- 姿态切换
- 部位状态变化
- 威胁动作组合变化

但随机性要受控，不能随机到题面失真。

### **4.4 Boss要有“高光窗口”**

高光窗口不只是多打几下，而是适合玩家释放：

- 灵魂铠甲技能
- 奥义
- 破韧追击
- 多武器切换连段

这样玩家才会感觉：这场 Boss 战是在兑现自己的构筑。

## **5. 具体Boss原型方案**

### **5.1 Boss 1：断角重卫**

**定位**

重甲、正面压制、部位解法型 Boss。用来验证“部位破坏 + 武器切换 + 破甲后爆发”。

**外观特征**

- 头部有夸张角甲
- 左臂是大型盾壁甲
- 胸口有灵能核心
- 下肢厚重，移动慢但压迫强

**核心机制**

- 正面防御极强
- 头角和盾臂是两个关键部位
- 未破甲前，弓类输出收益低
- 重武器对盾臂和角甲有更高破坏效率
- 破掉盾臂后，Boss 会进入短暂失衡
- 破掉头角后，部分冲撞技失效
- 胸口核心暴露后，远程/精准武器收益大幅提升

**战斗流程**

1. 前期顶压玩家，用正面防御和冲撞制造压力
2. 玩家需要先拿大剑/重武器处理盾臂或头角
3. 部位破坏后进入奖励窗口
4. 切弓或高速武器打核心，造成高额伤害
5. Boss 进入第二阶段，失去部分防御但攻击更激进

**验证点**

- 武器切换是否有明确意义
- 部位破坏是否有强反馈
- 玩家是否能从外观读出“先破甲再爆发”的解法
- 灵魂铠甲奥义是否能在核心暴露期形成高光

### **5.2 Boss 2：裂步狩影**

**定位**

高机动、姿态切换、反应窗口型 Boss。用来验证“敌方回合压力 + 快反 + 姿态变化”。

**外观特征**

- 轻甲、长肢、双刃
- 面部和腿部有高亮灵纹
- 姿态切换时发光区域不同

**核心机制**

- 三种姿态：
  - 猎杀姿态：高频突进
  - 回避姿态：高机动、低命中
  - 处决姿态：蓄力高威胁攻击
- 腿部是关键部位
- 切断腿部护甲后，机动性下降
- 快反成功会积累“压制值”
- 压制值满后可强制打入硬直期

**战斗流程**

1. Boss 用机动姿态不断拉扯，逼玩家处理快反
2. 玩家通过闪避/格挡反击建立压制值
3. 同时想办法处理腿部护甲
4. 机动性下降后，玩家进入真正的输出阶段
5. 第二阶段 Boss 提高处决技频率，形成更强反应压力

**验证点**

- 快反是否有足够正反馈
- 敌方回合是否真的有交互感
- 姿态系统是否带来清晰题面
- 这类 Boss 是否能体现灵魂铠甲防守插入的价值

### **5.3 Boss 3：多核寄生体**

**定位**

多部位联动、灵魂铠甲验证型 Boss。用来验证“灵魂铠甲高光 + 部位优先级 + 状态管理”。

**外观特征**

- 身上有多个寄生核
- 核心分布在肩、背、腹三处
- 不同核对应不同能力

**核心机制**

- 肩核激活时：远程压制增强
- 背核激活时：持续再生
- 腹核激活时：高伤冲击技解锁
- 玩家不能一口气处理所有核
- 必须判断本局优先拆哪个
- 灵魂铠甲技能对“核”有特殊克制或控制效果

**战斗流程**

1. Boss 根据当前存活核心改变战斗风格
2. 玩家根据 build 判断优先拆解顺序
3. 拆解特定核心后，Boss 风格明显变化
4. 拆完一定数量后进入本体脆弱期
5. 玩家用灵魂铠甲奥义打出收束高光

**验证点**

- 灵魂铠甲是否真的进入主策略层
- 玩家是否能根据不同构筑选不同拆核顺序
- 多部位机制是否成立而不杂乱
- 高光窗口是否和策略过程绑定

### **5.4 Boss 4：审判机关·双相体**

**定位**

基础线主 Boss 候选。综合验证“方案 B 主线 + 技能选择 + 战中解题 + 半即时潜力”。

**外观特征**

- 半机械、半灵体
- 具有“守序相”和“暴走相”
- 相位切换时外观和动作语言完全不同

**核心机制**

- 守序相：
  - 规则清晰
  - 动作慢
  - 强调技能与部位对应解法
- 暴走相：
  - 节奏更快
  - 技能组合更复杂
  - 更强调快反和即时压力
- 玩家需要在守序相建立优势，在暴走相兑现优势
- 如果处理不好，会被拖入长线消耗

**战斗流程**

1. 守序相：玩家观察并学习规则
2. 通过正确技能/武器处理关键部位
3. Boss 进入暴走相，敌方回合交互增强
4. 玩家用前面积累的资源、灵魂铠甲和切武器打爆发
5. 胜利高光来自“前期判断正确，后期成功兑现”

**验证点**

- 主线方案 B 能不能既有策略又不太传统
- 守序到暴走的双节奏是否成立
- 半即时化尝试是否值得继续做深
- 这类 Boss 是否适合作为第一版 Demo 的核心验证对象

## **6. 建议的首个Boss落地顺序**

如果现在要做第一个真正有代表性的 Boss，建议优先顺序是：

1. 断角重卫
2. 裂步狩影
3. 多核寄生体

原因：

- 第一个 Boss 优先验证基础主循环
- 第二个 Boss 验证节奏和反应层
- 第三个 Boss 再把灵魂铠甲和复杂部位策略做深

这样风险最可控。

## **7. 建议写进Boss规格的固定字段**

后续正式写 Boss 设计稿时，建议每个 Boss 固定包含：

- Boss 身份定位
- 主要威胁方式
- 核心题面
- 关键部位与其功能
- 推荐解法与可替代解法
- 姿态 / 阶段变化
- 敌方回合反应窗口
- 破韧 / 破甲 / 硬直奖励
- 灵魂铠甲的介入点
- 武器切换的价值点
- 失败原因应如何可见
- 本 Boss 要验证的系统问题

## **8. 收束结论**

M98 的 Boss 设计最重要的，不是“难”和“帅”本身，而是让玩家通过观察、判断、切换、反应和高光释放，真切地感受到：

**这场 Boss 战是在验证我打造出来的这个战士，而不是只在考我背招。**
